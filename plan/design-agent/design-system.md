# Design System Summary

## Experience goals

- Fluent, enterprise, Microsoft-style presentation
- Dense but approachable information hierarchy
- Shared visual language across all persona variants

## Core tokens

- **Brand**: blue-led Fluent palette tuned in `src/theme.ts`
- **Typography**: Segoe UI-first stack with strong title hierarchy and restrained body copy
- **Spacing**: 8px-derived spacing rhythm with 16px/24px/32px layout steps
- **Elevation**: soft card shadows with rounded 20px-24px containers
- **Backgrounds**: cool gray canvas with subtle gradients and white surfaces

## Shared primitives

- Hero masthead with command-bar actions
- Section headers with eyebrow, title, description, and optional actions
- Metric cards for KPI snapshots
- Shared card shells, badges, tables, progress bars, and checklist patterns
- Reusable loading and empty states

## Persona expressions

- **Market pulse dashboard**: denser metrics, holdings table, liquidity framing
- **Cash-flow planner**: calmer pacing, calendar/budget framing, larger progress surfaces
- **Bills action center**: task-first sequencing, approvals, and operational checklist emphasis

## Accessibility expectations

- High contrast text on all surfaces
- Keyboard-accessible Fluent components
- Clear status treatment through both wording and badge color
- Responsive layout collapse below tablet widths
