# QA-Agent Plan

## Mission

Perform final review, identify design or implementation issues, and route fixes to the correct agent.

## Inputs

- `/initial-request.md`
- `/plan/overview-memory.md`
- Logs and outputs from PM-Agent, SWE-Agent, and Design-Agent

## Tasks

1. Read the shared request spec
2. Review backend and frontend deliverables
3. Check for design inconsistencies, local issues, and implementation gaps
4. Record completed and in-progress work in `plan/QA-Agent/log.md`
5. Update `plan/overview-memory.md` with review status and required follow-ups

## Outputs

- Final review notes
- Routed follow-up tasks for the responsible agent
- Shared completion status in overview memory
